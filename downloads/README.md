# آرام — تایمر مراقبه و انرژی‌درمانی

[دانلود فایل نصب اندروید](./Aram.apk?raw=true)

نسخهٔ ۱.۰.۰؛ برای اندروید ۸ و بالاتر.

امکانات: تایمر اصلی، زنگ دوره‌ای با دقت ثانیه، صدای مستقل و انتخاب فایل صوتی گوشی، صدای کاسهٔ تبتی داخلی، مکث و ادامه، اعلان کنترل جلسه، ادامه با صفحهٔ خاموش، تاریخچهٔ شمسی و خروجی CSV.

فایل را روی گوشی دانلود و باز کنید. در صورت درخواست اندروید، نصب از منبع مورد استفاده را مجاز کنید.

ساخت و امضای APK بررسی شده است. ۱۲ آزمون محاسباتی و ۱۵ بررسی عملکردی در شبیه‌ساز اندروید ۱۰، شامل اجرای جلسه با صفحهٔ خاموش، موفق بوده‌اند. آزمون روی گوشی فیزیکی انجام نشده است.

برنامه نیازی به حساب یا اینترنت ندارد و تاریخچه روی دستگاه ذخیره می‌شود. فایل APK با کلید محلی توسعه امضا شده و برای نصب مستقیم است.
